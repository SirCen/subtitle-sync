It patches the Jellyfin server at runtime and is not maintained by this project, so it can break on a Jellyfin update. Nothing else here depends on it.
Sync a subtitle track
Pick a film or episode, choose the track that drifts, and re-time it against the audio. The analysis runs in this browser.
